# 分阶段计划

## v0.1：已完成

- 单链路贝叶斯定位、路径签名检查、按信息增益／成本推荐下一条探测。
- 从带标签数据学习噪声参数，与失败路径投票、逻辑回归比较。
- 按拓扑划分数据，保留噪声变化、漏采和重复告警实验。
- CLI、Python API、离线报告、原始数据与逐例结果。

首版回答的是：在明确假设下，哪些探测有助于定位，哪些观测不足以区分故障。

## 下一阶段：验证网络数据，而不只验证生成器

| 研究问题 | 工作 | 验收证据 |
| --- | --- | --- |
| 实际探测的噪声是否符合模型 | 用可控网络注入丢包／断链，记录路径和时间窗口 | 独立采集的带标签数据、采集脚本、失败与成功原始记录 |
| 重复和相关告警导致过度自信 | 按事件分组，并比较相关噪声模型与简单去重 | 相同测试集上的误判、覆盖率、NLL 和错误案例 |
| 多条链路故障时会误导到哪里 | 加入多故障候选与模型不匹配检查 | 多故障对照、候选数和推断开销，不能只报 Top-1 |
| 路由变化使路径证据过期 | 给拓扑和探测绑定时间窗口，保留路径版本 | 有路由变化的对照数据和过期证据案例 |

目前没有真实网络部署、故障恢复时间或费用节省的测量。

## 后续大模型实验

把同一故障任务导出为探测日志文本和拓扑图，对比文本、图像、图文输入；
加入“告警相同、拓扑不同”的反事实样例，检查模型是否使用拓扑信息。
训练、评测按拓扑分组，不能按图像随机拆分。

先跑零样本与传统算法基线，再做 LoRA；固定数据、模型 revision、有效 batch 和训练预算。
记录实际日志与错误分析。最后才测试四卡训练、显存与通信瓶颈。
